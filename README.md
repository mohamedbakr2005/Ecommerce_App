# 🛒 E-Commerce App

A full-featured E-Commerce project built with **.NET API** for the backend and **Flutter** for the frontend, providing a seamless experience for product browsing, category management, cart handling, and authentication.

---

## 🚀 Features

- **Authentication (Login & Register)**
- **Product Management**
- **Category Management**
- **Shopping Cart Management**
- Modern and user-friendly Flutter UI
- **Backend powered by .NET API** following best practices

---

## 🛠️ Tech Stack

- **Frontend:** Flutter, Bloc/Cubit
- **Backend:** ASP.NET Core Web API
- **Database:** SQL Server
- **Authentication:** JWT Tokens
- **State Management:** flutter_bloc
